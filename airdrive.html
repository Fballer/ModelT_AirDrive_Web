Porta MT: AirDrive Quick Reference & Guide

1. Initial Bootstrap & Installation

To load the AirDrive software suite on a freshly wiped or new TRS-80 Model 100 / Model 102 / Tandy 200:

  1. Turn ON Model 100/200 and ensure the AirDrive is connected to the RS-232 DB-25 port.
  2. From the Model 100/200 main menu, press Enter on BASIC.
  3. Type RUN "COM:98N1E" (Model 100/102) or RUN "COM:98N1ENN" (Model 200) and press Enter.
  4. Within 15 seconds, press and hold the button on the AirDrive (under 2s for Model 100, 3s+ for Model 200).
  5. The system will automatically install TSLOAD.CO and create the AIRDRV.BA system menu.

2. The AIRDRV.BA System Menu

Running AIRDRV.BA provides instant access to all AirDrive capabilities:

  • Model 100/102 Menu:
    • 1: BT-Keyboard — Use the Model 100 keyboard wirelessly with your modern PC, Mac, iPad, or phone.
    • 2: TS-DOS (Floppy) — Launch Traveling Software TS-DOS for full floppy disk operations across 5 virtual drives.
    • 3: Virtual DVI — Activate high-speed wireless 80-column external CRT display on Tab 2 of this browser app!
    • 4: BT Modem/Web/BBS — Launch wireless Bluetooth Modem & Internet Bridge: live weather, news feeds, and Telnet BBS dialer!
    • 5: PAKU-100 (Maze) — Chomping maze game.
    • 6: Block-TRS (Blocks) — Falling block puzzle.
    • 7: Pipe-100 (Pipes) — Inspired by Pipe Dream.
    • 8: Mine-100 (Mines) — Inspired by Minesweeper.
    • Q: Quit — Return cleanly to the TRS-80 Model 100 main menu.
  • Model 200 Menu:
    • 1: Bluetooth Keyboard
    • 2: TS-DOS (TPDD Floppy)
    • 3: BT Modem/Web/BBS — Launch wireless Bluetooth Modem & Internet Bridge on Model 200!
    • 4: Chomp-200 (Pellet Eating Maze Game)
    • 5: Block-TRS (Dropping Blocks Puzzle)
    • 6: Pipe-200 (Inspired by Pipe Dreams)
    • 7: Mine-200 (Inspired by Mine Sweeper)
    • 8: Quit to Main Menu

4. Web & BBS Internet Bridge Instructions

The Web & BBS Bridge connects your vintage TRS-80 Model 100/102 or Tandy 200 directly to live internet resources and Telnet bulletin boards without requiring any TCP/IP hardware on the vintage computer:

  • 40-Col Standard vs 80-Col Ultrascreen: When launching Web/BBS in AIRDRV.BA, press [4] for native ROM font or [8] for the micro-font 80-column Ultrascreen driver loaded automatically from AirDrive flash into protected high memory.
  • Single-Key Navigation: When reading news or weather, text is neatly paginated so nothing scrolls unreadable off your LCD. Press [Space] or [Enter] for Next Page, [B] for Previous Page, and [M] to return to the Bridge Menu.
  • Direct Keyboard BBS Dialing: You can dial any vintage BBS directly from your Model T keyboard by typing ATDT host:port (e.g. ATDT bbs.fozztexx.com:23).
  • Safe Memory Cleanup: Pressing [F8] safely exits the bridge, closes the COM port, unhooks Ultrascreen, reclaims protected RAM with CLEAR 256, MAXRAM, and restores AirDrive TPDD disk mode.
