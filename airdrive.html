Porta MT: AirDrive Quick Reference & Guide

1. Initial Bootstrap & Installation

To load the AirDrive software suite on a freshly wiped or new TRS-80 Model 100 / Model 102:

  1. Turn ON Model 100 and ensure the AirDrive is connected to the RS-232 DB-25 port.
  2. From the Model 100 main menu, press Enter on BASIC.
  3. Type RUN "COM:98N1E" and press Enter.
  4. Within 15 seconds, press and hold the button on the AirDrive for under 2 seconds.
  5. The system will automatically install TSLOAD.CO and create the AIRDRV.BA system menu.

2. The AIRDRV.BA System Menu

Running AIRDRV.BA from the Model 100 menu provides instant access to all AirDrive capabilities:

  • 1: BT-Keyboard — Use the Model 100 keyboard wirelessly with your modern PC, Mac, iPad, or phone.
  • 2: TS-DOS (Floppy) — Launch Traveling Software TS-DOS for full floppy disk operations across 5 virtual drives.
  • 3: Virtual DVI — Activate high-speed wireless 80-column external CRT display on Tab 2 of this browser app!
  • 4: PAKU-100 — Chomping maze game.
  • 5: Block-TRS — Falling block puzzle.
  • 6: Pipe-100 — Inspired by Pipe Dream.
  • 7: Mine-100 — Inspired by Minesweeper.
  • Q: Quit — Return cleanly to the TRS-80 Model 100 main menu.
