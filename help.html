Porta MT: AirDrive Manager - User Guide

1. Getting Started

The AirDrive Manager connects to your Virtual Disk drive via Web Bluetooth. Ensure your device is powered on, and click the Connect AirDrive button. You must give the browser permission to connect to the Bluetooth device.

APPLE MAC USERS - CRITICAL BLUETOOTH STEP:
Because the AirDrive acts as a Keyboard hardware device, Apple macOS will aggressively "lock" the device for security reasons if you pair it via the main Apple System Settings. If the Mac System owns the device, Chrome will be permanently blocked from seeing the File System.

Fix: Open your Mac Bluetooth Settings, find the AirDrive, and click "Forget This Device". Do not pair it there. Instead, return to this webpage and click "Connect AirDrive" and pair it exclusively through the secure browser popup!

Supported Platforms & Browsers

The AirDrive Manager uses the Web Bluetooth API and the File System Access API. Support varies across devices:

  • macOS / Windows / Linux / ChromeOS:
    • Google Chrome: (Recommended) Full Support.
    • Microsoft Edge: Full Support.
    • Opera / Brave: Generally Supported.
    • Safari & Firefox: Not Supported.
  • Android:
    • Google Chrome: Supported for file management. Note: Modern "Save File" pickers may fall back to standard downloads.
  • iPhone / iPad (iOS):
    • Safari, Chrome, & Edge: Not Supported (Apple blocks Web Bluetooth in these apps).
    • Bluefy Browser (App Store): Works as a workaround to enable Bluetooth within a browser environment on iOS.

2. Navigating Virtual Disks

The AirDrive supports 5 distinct virtual floppy disks arranged in a carousel. Click any disk in the background stack to bring it to the front and make it the Active Drive.

  • The active drive's files will automatically list in the white center label.
  • Click any file in the label to highlight and select it for commands.

3. Managing Your PC Directory

The black box at the bottom of the screen allows you to select a local folder on your computer.

  • Click Select PC Folder to choose a working directory (like 'Downloads').
  • Files from this folder can be safely synchronized with your virtual disks.

4. Uploading & Downloading Files

To copy a file to the AirDrive: Either drag a file from your connected PC Directory list UP to the active blue floppy disk, or drag a file directly from Finder/Desktop onto the active (front) disk. You will be prompted to fit the name to Model 100 limits (6.2).

To copy a file to your PC: You can either click the file in the virtual floppy and press COPY Selected Files to PC, OR click and drag the file from the topmost virtual disk DOWN into the black PC directory area.

5. Virtual Disk Commands

Use the control panel on the right side of the screen to manage the files currently on the active Virtual Disk:

  • RENAME Selected File: Change the name of the file (limited to 6 character name + 2 character extension per Model 100 specifications).
  • DELETE/KILL Selected File: Permanently delete the file from the AirDrive hardware.
  • FORMAT Select Virtual Disk: Instantly wipe all files currently residing on the active virtual disk number. This cannot be undone!
  • BACKUP entire selected Virtual DISK: Downloads a .zip of the active disk (diskN/FILENAME inside). Restore later with the Restore button.
  • RESTORE Backup from PC to Virtual Disk: Pick that zip. Disk N in the zip is formatted and replaced. A 5-disk zip restores only the folder that matches the active disk.
  • BACKUP 5-Disks All / RESTORE 5-Disks All: Same zip layout with disk1 through disk5. Mass restore formats every virtual disk first.
Stay on the page until the progress bar finishes. A second backup or copy is ignored while one is running. Use Chrome or Edge. The zip is built in the browser over Bluetooth — no extra firmware command.

6. Troubleshooting: macOS Bluetooth Won't Reconnect

On macOS, Web Bluetooth sometimes drops the Model T AirDrive session and will not re-establish it. The browser picker may show nothing, or Connect appears to hang, even though the AirDrive is on and advertising.

A reliable workaround:

  1. Open System Settings → Bluetooth.
  2. Find Model T AirDrive in the device list.
  3. Click Forget This Device (or Forget / Remove).
  4. Return to this webpage and click Connect AirDrive.
  5. Pair again from the browser popup — do not pair it from macOS Settings.

After forgetting, the AirDrive should show up again in the Chrome/Edge Bluetooth picker. This is a macOS / HID ownership quirk, not a dead radio; keep this step handy whenever a previously working connection refuses to come back.
